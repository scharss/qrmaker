# QR Space - QR Code Generator

![QR Space Logo](https://img.shields.io/badge/QR%20Space-QR%20Generator-blue)

QR Space is a modern, user-friendly web application for generating custom QR codes. It allows you to create QR codes for both URLs and text, featuring color customization options and high-resolution downloads.

## 🌟 Features

- ✨ Instant QR code generation
- 🎨 Color customization (QR and background)
- 📱 Modern, responsive design
- 🔄 Real-time updates
- 📥 High-resolution download (1080x1080)
- 🔍 URL validation
- 🎯 Intuitive, user-friendly interface

## 🚀 Technologies Used

- HTML5
- CSS3 (with CSS variables and media queries)
- Vanilla JavaScript
- [QRCode.js](https://github.com/davidshimjs/qrcodejs) for QR generation
- [Font Awesome](https://fontawesome.com/) for icons

## 💻 Installation and Usage

1. Clone the repository:
```bash
git clone https://github.com/your-username/qr-space.git
```

2. Open the `index.html` file in your web browser

3. You're all set! You can start generating QR codes right away

## 🛠️ How to Use

1. **Enter your content**:
- Type a URL or text into the input field
- Select the content type (URL or text)

2. **Customize your QR**:
- Adjust the QR code color
- Modify the background color
- View changes in real-time

3. **Download your QR**:
- Click the "Download QR" button
- The QR code will download in high resolution (1080x1080)
